# 🇦🇷 Qatar 2022 World Cup Experience

Una experiencia interactiva inspirada en la Copa Mundial FIFA Qatar 2022.

Proyecto frontend desarrollado con una introducción cinematográfica, animaciones, presentación del campeón y un fixture interactivo del torneo.

La idea principal es recrear la emoción de un Mundial mediante una interfaz moderna, con transiciones suaves, elementos visuales y una navegación centrada en la experiencia del usuario.

---

## ✨ Características

- 🎬 Pantalla de carga animada estilo presentación deportiva
- 🏆 Animación de la Copa del Mundo
- 🇦🇷 Identidad visual inspirada en Argentina
- 🌎 Hero principal con ambiente de estadio e hinchada
- 🏟️ Presentación del Mundial Qatar 2022
- ⚽ Fixture interactivo del torneo
- 🥇 Tarjeta final del campeón
- 🎞️ Animaciones con transiciones fluidas
- 📱 Diseño responsive

---

## 🛠️ Tecnologías utilizadas

- React
- TypeScript
- Vite
- Tailwind CSS
- Framer Motion
